A single-file Python program that draws a newspaper front page summing up the world news of 20 November 2026 — Russian missiles landing in Poland during a huge barrage on Ukraine, the AI stock sell-off that pushed markets into correction, Peru's magnitude 6.7 earthquake, the UK-EU reset deal in Brussels, and Houthi missiles hitting Riyadh as tankers burned in Hormuz — as one 1024x1024 PNG, drawn entirely with code (a hand-made bitmap font, no external assets) using only the Python standard library.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
